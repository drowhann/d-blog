# nuxt-sql-inspector

A dev-only Nuxt module that maps each API request to the SQL it ran. I built it so I could see slow queries, duplicates, and parallel work without leaving the app.

It works on **Nuxt 3** and **Nuxt 4**, with `pg` / `postgres.js`, `mysql2`, `@libsql/client`, `better-sqlite3`, and **db0** (`useDatabase()`).

![SQL inspector: request list, waterfall, and query detail](/images/nuxt-sql-inspector.png)

Open `/__sql_queries` in development, or the **SQL** tab in Nuxt DevTools. The UI lists requests, highlights slow SQL, flags repeated queries, and shows a waterfall so you can tell sequential vs parallel execution.

```bash
pnpm add -D nuxt-sql-inspector
```

```ts
export default defineNuxtConfig({
  modules: ['nuxt-sql-inspector'],
})
```

Wrap your client once, using the import that matches the driver:

```ts
import { inspectSql } from 'nuxt-sql-inspector/node-postgres'
const pool = inspectSql(new Pool({ connectionString }))
```

Source is on [GitHub](https://github.com/drowhann/nuxt-sql-inspector).
